01. eBPF 기반 Kubernetes 위협 관측 시스템

2025.11 ~ 2026.02 6 Members 탐지 및 분석 엔진 개발 eBPF, ClickHouse, Fluentd, K8s

커널 레벨 텔레메트리를 활용한 실시간 컨테이너 위협 분석

실무 인프라 보안 요구사항을 충족하기 위해 컨테이너 종료 시 소멸되는 로그의 한계와 트래픽 병목 현상을 해결하는 Zero-Drop 파이프라인을 구축했습니다.

Problem

이벤트 유실 및 단절

트래픽 급증 시 유저 공간 수집의 병목으로 보안 이벤트가 드롭되며, 이기종 로그 간의 단절로 공격자의 수평 이동 경로 추적이 불가능했습니다.

Approach

커널 데이터 수집 & 베이스라인 탐지

eBPF(Tetragon)를 통해 커널 내부에서 직접 데이터를 필터링하고, 공통 식별자(8-Tuple)를 기반으로 베이스라인 기반 네트워크 이상 탐지 로직을 구현했습니다.

Result & Impact

분석 속도 5.06배 향상

ClickHouse 고속 쿼리 적용으로 레이턴시를 1.968s에서 0.389s로 단축하여 실시간 위협 식별이 가능해졌습니다.

수집 안정성 확보

고부하 상황에서도 데이터 드롭을 방지하고 커널 레벨의 가시성을 안정적으로 확보하여 신뢰성을 높였습니다.

01. Architecture & Key Decisions

User-space 한계 극복을 위한 eBPF 도입

Context Switching 오버헤드 원천 차단: 기존 방식은 피크 환경에서 로그 드롭이 빈번했습니다. 커널 내부에서 이벤트를 직접 제어하는 eBPF(Tetragon) 기술을 채택하여 오버헤드를 최소화하고 수집 안정성을 확보했습니다.

대규모 OLAP 처리를 위한 ClickHouse 채택

이기종 로그의 실시간 상관분석: OpenSearch의 조인 연산 지연 한계를 극복하고자 대규모 처리에 최적화된 ClickHouse를 도입했습니다. 정규화된 고속 상관쿼리 구조를 설계하여 IR 팀의 초동 대응 시간을 획기적으로 단축했습니다.

02. 포렌식 아티팩트 기반 CTI 분석 엔진 (FACT)

2026.03 ~ 2026.05 1 Member (Private) 탐지 및 분석 엔진 개발 Rust, Python, STIX 2.1, Vector DB

고성능 파이프라인 기반의 원스톱 CTI 자동화 구현

개별 분석 도구 사용으로 인한 맥락 단절과 골든타임 상실 문제를 해결하기 위해 통합 지능형 포렌식 엔진을 설계했습니다.

Problem

수동 분석으로 인한 리소스 낭비

MFT, Registry, Event Logs 등 각각 분산된 도구들로 인해 데이터를 수동으로 대조해야 했으며, 이는 사고 분석 리소스 과소비로 이어졌습니다.

Approach

병렬 파이프라인 & 데이터 표준화

Rust 기반 병렬 수집부터 CTI 연동까지의 과정을 자동화하고, 도출된 결과물을 STIX 2.1 표준으로 변환하여 범용성을 갖췄습니다.

Result & Impact

약 45초 만에 풀 파싱 완료

Rust 병렬 처리 최적화를 통해 핵심 아티팩트 파싱 및 분석 소요 시간을 1000GB 기준 약 45초로 획기적으로 단축했습니다.

의사결정 100% 자동화

데이터 추출부터 LLM(RAG) 기반 대응 지침 도출까지 전 과정을 자동화하여 위협 판단의 정확도를 비약적으로 높였습니다.

02. Architecture & Key Decisions

1. Evidence Collector
2. High-speed Rust Parser (MFT, Reg, Evtx)
3. STIX 2.1 Object Modeler
4. LLM RAG Analyzer

타임라인 기반 아티팩트 상관분석

공격 시나리오 자동 재구성: 단편적인 아티팩트만으로는 전체 위협 흐름 파악이 어렵다는 점을 해결하기 위해, PID 및 파일 경로를 키값으로 활용한 그래프 기반 상관분석 모델을 자체 설계하여 시나리오를 가시화했습니다.

STIX 2.1 기반 위협 인텔리전스 규격화

국내 CTI 공유 커뮤니티 기여를 위한 기반: 데이터가 내부망에만 고립되지 않도록 가공된 데이터를 STIX 2.1 표준으로 매핑했습니다. 이는 향후 국내외 CTI 생태계 확장 및 인텔리전스 공유 시스템에 실질적으로 기여할 수 있는 호환성을 제공합니다.
