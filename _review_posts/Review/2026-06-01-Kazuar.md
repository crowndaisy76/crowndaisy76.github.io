# [Executive Summary]
본 보고서는 러시아 국가 배후 위협 그룹인 Secret Blizzard가 장기적인 사이버 에스피오나지 및 민감 첩보 수집을 목적으로 운용 중인 고도화된 .NET 기반 백도어 프레임워크 Kazuar에 대한 분석 리포트이다. 해당 위협 프레임워크는 과거의 전통적인 단일형 백도어 아키텍처에서 완전히 벗어나, 감염된 호스트들이 서로 통신하며 독자적인 무력화 경계를 형성하는 {% include wiki_link.html text="P2P" url="/review/Details/P2P" %} 봇넷 형태로 진화하여 타깃 환경에 대한 지속적이고 강력한 은닉 접근 채널을 제공하고 있다.

일반적인 고도화 위협 그룹들이 보안 솔루션의 감시를 피하기 위해 운영체제 내장 도구를 악용하는 Living off the Land 기법에 의존하는 것과 달리, Kazuar는 정교하게 설계된 모듈형 기능 분할 아키텍처를 채택하여 탐지를 무력화한다. 특히 강력한 다중 레이어 소스코드 난독화와 동적 심볼 분석 기법을 결합하여 정적 탐지 체계를 완전히 우회하며, 각 기능을 독립된 모듈로 세분화하여 실행함으로써 엔드포인트 보안 솔루션의 행위 기반 프로파일링 감시망을 무력화하는 고도의 신뢰성을 보여준다.

# [Technical Analysis]

## 1. Initial Access

Secret Blizzard는 보안 솔루션의 정적 시그니처 탐지망을 무력화하고 유연한 침투를 달성하기 위해, 여러 유형의 드로퍼 아키텍처를 다각적으로 활용하여 Kazuar 프레임워크를 유포하였다. 초기 침투 기법 중 하나인 Pelmeni 드로퍼는 암호화된 2단계 페이로드를 드로퍼 바이너리 내부 리소스에 직접 임베디드 형태로 저장하여 운용하는 일체형 구조를 취한다. 반면, 또 다른 형태의 침투 시나리오에서는 최종 페이로드의 노출을 숨기기 위해 독립된 .NET 로더와 암호화된 페이로드를 분리하여 배포하는 방식을 구사하였다. 이 분리형 드로퍼는 시스템 진입 후 중간 매개체인 .NET 로더를 가동한 뒤, 동적으로 복호화한 Kazuar 최종 페이로드를 해당 로더에 스트림 형태로 전달한다. 로더는 전달받은 페이로드를 디스크에 파일로 작성하지 않고 메모리 상에서 직접 호출 및 실행하는 인메모리 인젝션 기법을 수행함으로써, 엔드포인트 파일 시스템 감시 프로세스를 완전히 우회하고 초기 거점을 은밀하게 확보하는 치밀함을 보여주었다.

## 2. Execution & Persistence

Kazuar 프레임워크의 핵심 구동체는 고도로 모듈화된 .NET 기반의 자동화 엔진으로 설계되었다. 시스템 내부에서 실행 주도권을 확보한 악성코드는 단일 루틴으로 움직이지 않고, 정찰, 탈취, 통신 등 세부 임무에 따라 독립된 하위 컴포넌트들을 메모리에 동적으로 로드하여 가동하는 오케스트레이션 방식을 취한다. 이는 엔드포인트 보안 솔루션이 단일 프로세스의 행위 임계치를 기준으로 공격을 탐지하고 차단하기 어렵게 만드는 기술적 기반이 된다.

동시에 공격 그룹인 Secret Blizzard는 대상 시스템에 대한 장기적인 제어권을 유지하기 위해 다중화된 지속성 확보 기법을 구사한다. 일반적으로 Windows 스케줄러를 통한 악성 작업 등록과 레지스트리 자동 실행 키 변조를 동시에 전개하며, 호스트의 시동 단계부터 백그라운드 서비스 형태로 은밀히 상주하도록 설정한다. 특히 시스템 내 정상적인 서비스나 컴포넌트의 신뢰 흐름에 기생하는 방식을 채택하여, 시스템 관리자가 일반적인 프로세스 트리나 부팅 항목 점검만으로는 악성코드의 상주 여부를 쉽게 인지하지 못하도록 은폐하였다.

## 3. Defense Evasion

Kazuar가 보여주는 가장 강력한 차별점은 정적 및 동적 분석을 무력화하기 위해 설계된 다중 레이어 방어 회피 전술이다. 개발 단계에서부터 소스코드 전체에 고도화된 난독화를 적용하여 보안 솔루션의 시그니처 매칭과 리버스 엔지니어링 시도를 원천 차단한다. 또한 실행 중에 필요한 Windows 내부 API 시스템 함수들을 코드 내에 정적으로 선언하지 않고, 런타임 시점에 메모리 상에서 함수 주소를 동적으로 찾아내어 호출하는 동적 API 분석 레이어를 구현함으로써 가져오기 주소 테이블 분석 기반의 탐지망을 우회한다. 내부 구성 파일과 통신 데이터 역시 독자적으로 커스텀된 암호화 알고리즘으로 이중 밀봉되어 있으며, 가상화 분석 환경이나 디버깅 도구를 감지하면 즉시 행위 프로파일을 가변적으로 변화시키는 안티 분석 루틴을 상시 가동한다.

## 4. Credential Access & Discovery

Kazuar의 최종 목표인 사이버 에스피오나지를 달성하기 위해 자격 증명 탈취 및 정찰 기능은 매우 정교하고 자동화된 형태로 수행된다. 시스템 내부 장악이 완료되면 내부망 확장의 교두보를 마련하기 위해 호스트 내의 자격 증명 저장소를 집중적으로 공략한다. 시스템 전반에 걸쳐 다양한 웹 브라우저에 저장된 쿠키 데이터, Outlook을 포함한 메일 클라이언트의 세션 정보, 그리고 시스템 메모리 내부 및 로컬 보안 계정 관리자에 상주하는 자격 증명 해시를 통째로 복호화하여 덤핑하는 고위험 기술을 전개한다.

이와 동시에 공격자는 감염된 호스트를 기점으로 주변 네트워크 인프라 전체를 매핑하기 위해 전방위적인 정찰 작업을 수행한다. 로컬 시스템의 상세한 하드웨어 명세와 실행 중인 보안 프로세스 목록을 수집하는 것은 물론이고, {% include wiki_link.html text="Active Directory" url="/review/Details/AD" %} 도메인 컨트롤러와의 연결 상태, 내부망의 공유 자원 현황 및 상세한 네트워크 토폴로지를 정밀하게 스캔하여 정찰 데이터를 축적한다.

## 5. Command and Control

전통적인 백도어들이 단일 중앙 집중식 C2 서버의 차단으로 권한을 상실하는 것과 달리, Kazuar는 감염된 호스트들을 상호 연결하는 독자적인 P2P 봇넷 아키텍처를 도입하여 치명적인 회복 탄력성을 확보하였다. 이 구조에서 감염된 각 호스트는 외부 명령을 전달하고 내부 데이터를 릴레이하는 프록시 노드 역할을 동시에 수행한다. 공격자는 중앙 마스터 C2의 노출을 최소화하기 위해 다단계 터널링 통신을 구현하였으며, 특정 C2 도메인이 차단되더라도 주변의 다른 감염 노드들을 통해 실시간으로 통신 경로를 재구축하는 자가 치유 능력을 보여준다. 수집된 모든 민감 첩보는 이 분산형 P2P 통신망 채널을 통해 안전하게 암호화되어 최종 수집 서버로 반출된다.

# [MITRE ATT&CK Mapping]

## Initial Access

* **Ingress Tool Transfer** - [T1105](https://attack.mitre.org/techniques/T1105/)
    
    Pelmeni 드로퍼 등 다각화된 드로퍼 변종 및 분리형 .NET 로더 시스템을 결합하여 가용망을 뚫고 최종 Kazuar 페이로드를 타깃 시스템 내부로 전달함.

## Execution

* **Reflective Code Loading** - [T1620](https://attack.mitre.org/techniques/T1620/)

    드로퍼에 의해 구동된 .NET 로더가 암호화된 바이너리를 동적으로 복호화한 후, 디스크에 쓰지 않고 메모리 공간 상에서 직접 로드하여 실행 주도권을 확보함.

* **Command and Scripting Interpreter** - [T1059](https://attack.mitre.org/techniques/T1059/)

    고도로 모듈화된 .NET 기반 자동화 엔진을 기반으로 정찰, 탈취, 통신 목적의 독립 하위 컴포넌트들을 유기적으로 제어하고 오케스트레이션을 수행함.

## Persistence

* **Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder** - [T1547.001](https://attack.mitre.org/techniques/T1547/001/)
    
    감염된 시스템이 재부팅된 이후에도 은밀하게 자동 구동될 수 있도록 윈도우 레지스트리의 자동 실행 키 항목을 무단 변조함.

* **Scheduled Task/Job: Scheduled Task** - [T1053.005](https://attack.mitre.org/techniques/T1053/005/)
    
    시스템 초기 시동 단계 및 백그라운드 서비스 상주를 보장하기 위해 Windows 스케줄러 시스템에 주기적 실행을 보장하는 악성 작업을 영구 등록함.

## Defense Evasion

* **Obfuscated Files or Information: Software Packing** - [T1027.002](https://attack.mitre.org/techniques/T1027/002/)
    
    보안 솔루션의 정적 시그니처 탐지를 무력화하고 코드 분석을 교란하기 위해 .NET 소스코드 전체에 강력한 다중 레이어 난독화를 적용함.

* **Native API** - [T1106](https://attack.mitre.org/techniques/T1106/)

    윈도우 시스템 내부 함수 호출 시 정적 선언 방식을 배제하고, 런타임 시점에 메모리 공간에서 직접 함수 주소를 찾아내 가동하는 동적 API 분석 레이어를 적용하여 가져오기 주소 테이블 분석 기반의 탐지망을 우회함.

* **Virtualization/Sandbox Evasion** - [T1497](https://attack.mitre.org/techniques/T1497/)
    
    분석가의 샌드박스, 디버거, 가상화 동적 분석 환경이 감지될 경우 악성 행위를 즉각 중단하고 정상 프로세스처럼 동작을 가변적으로 은닉하는 안티 분석 메커니즘을 구동함.

## Credential Access

* **Credentials from Password Stores** - [T1555](https://attack.mitre.org/techniques/T1555/)
    
    시스템 장악 이후 다양한 웹 브라우저 내부에 보관된 쿠키 자산 및 Outlook 등 메일 클라이언트의 중요 세션 자격 증명을 통째로 추출하고 평문 복호화함.

* **OS Credential Dumping** - [T1003](https://attack.mitre.org/techniques/T1003/)
    
    내부망 횡적 이동의 확고한 교두보를 마련하기 위해 메모리 내부에 보관된 인증 토큰 및 로컬 보안 계정 관리자 세션의 해시 데이터를 무단 덤핑함.

## Discovery

* **System Information Discovery** - [T1082](https://attack.mitre.org/techniques/T1082/)
    
    타깃 호스트의 세부 아키텍처 명세, 하드웨어 장치 정보 및 운영체제 빌드 수준을 파악하기 위해 전방위 정찰 조사를 수행함.

* **Software Discovery: Security Software Discovery** - [T1518.001](https://attack.mitre.org/techniques/T1518/001/)
    
    가동 중인 백신 프로그램이나 엔드포인트 보안 프로세스의 기동 현황 목록을 정밀 탐색하여 방어 수단을 사전 파악함.

* **System Network Configuration Discovery** - [T1016](https://attack.mitre.org/techniques/T1016/)
    
    감염 단말을 거점으로 액티브 디렉터리 도메인 컨트롤러와의 통신 상태, 공유 네트워크 리소스 및 사내 전반의 토폴로지 연결 현황을 매핑함.

## Command and Control

* **Proxy: Multi-Hop Proxy** - [T1090.003](https://attack.mitre.org/techniques/T1090/003/)
    
    중앙 C2 서버 차단에 유연하게 대응하고 노출을 감추기 위해, 감염된 호스트들을 프록시 노드로 전출시켜 상호 명령을 릴레이하는 분산형 P2P 봇넷 토폴로지를 구축함.

* **Application Layer Protocol** - [T1071](https://attack.mitre.org/techniques/T1071/)
    
    노드 간 상호 명령 수립 및 데이터 유출을 수행할 때 일반적인 웹 트래픽 규격과 커스텀 암호화 알고리즘을 융합하여 네트워크 보안 모니터링 탐지망을 정교하게 우회함.
