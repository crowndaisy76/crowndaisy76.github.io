# [Executive Summary]

본 보고서는 2025년부터 2026년 초에 걸쳐 식별된 고도화된 지능형 지속 위협 그룹 Cloud Atlas의 원격 제어 및 정보 탈취 목적의 사이버 에스피오나지 캠페인에 대한 분석 리포트이다. 해당 위협 그룹은 고유의 기술적 은닉 전술을 바탕으로 러시아와 벨라루스의 주요 정부 기관, 외교 부문 및 민간 핵심 기업들을 정밀 표적으로 삼아 광범위한 침해 공작을 전개하였다.

Cloud Atlas는 초기 침투 단계에서 사용자의 심리를 교묘히 악용하는 악성 바로가기(LNK) 파일 기반의 피싱 이메일을 주축으로 활용하였다. 이들은 타깃 조직 내부로 진입한 직후, 이번 캠페인에서 새롭게 식별된 신종 PowerShell 백도어인 PowerCloud를 구동하여 엔드포인트 보안 솔루션의 정적 시그니처 탐지망을 무력화하고 초기 거점을 은밀하게 확보하는 치밀함을 보였다.

특히 본 캠페인의 핵심적인 전술적 특징은 공격 인프라의 은폐와 추적 차단을 위해 대중적으로 널리 사용되는 공개 유틸리티 및 오픈소스 소프트웨어를 적극적으로 도용 및 변조했다는 점이다. 이들은 합법적인 원격 제어 도구인 OpenSSH를 무단 변조하여 시스템에 상주시추고, RevSocks와 같은 리버스 터널링 도구 및 Tor 익명 네트워크 아키텍처를 복합적으로 결합하여 C2 서버와의 암호화된 명령 제어 채널을 수립하였다. 이러한 다단계 프록시 및 터널링 구성은 일반적인 네트워크 트래픽 모니터링 환경에서 공격자의 실질적인 악성 패킷 흐름을 탐지하기 어렵게 만들며, 장기적인 첩보 활동을 영위하기 위해 위협 그룹의 은닉 인프라가 더욱 정교화되었음을 시사한다.

# [Technical Analysis]

## 1. Initial Access & Execution

Cloud Atlas 위협 그룹은 타깃 조직의 내부망 경계선을 돌파하기 위해 정밀하게 기획된 스피어 피싱 전술을 최초 침투 벡터로 지속 활용하고 있다. 이들은 주로 악성 바로가기(LNK) 파일이 내장된 ZIP 압축 아카이브를 이메일에 첨부하여 발송하는 방식을 구사하며, 피해자가 파일의 압축을 해제하고 원격 코드 실행을 유발하는 LNK 자산을 직접 실행하도록 유도하는 사용자 실행 전술을 전개한다.

이러한 바로가기 파일 기법 외에도, 공격자는 마이크로소프트 오피스 수식 편집기의 오래된 문서 취약점인 CVE-2018-0802를 교차 악용하는 악성 문서를 함께 유포하여, 피해자가 문서를 여는 즉시 외부 리소스 서버로부터 추가 악성 페이로드를 다운로드하고 실행하도록 아키텍처를 다각화하였다.

피해자가 악성 바로가기 파일을 실행하면, 내부에 은닉되어 있던 파라미터 명령어가 커맨드 라인 인터페이스를 통해 백그라운드에서 즉각 가동된다. 이는 외부 원격 서버에 호스팅된 악성 PowerShell 스크립트를 실시간으로 호출하여 호스트 메모리에 동적으로 로드시키는 실행 파이프라인을 형성한다. 메모리 상에서 구동을 시작한 초기 스크립트는 네트워크 연결 상태나 원격 인프라의 가용 여부에 구애받지 않고 메인 페이로드를 안정적으로 가동하기 위해, 로컬 임시 폴더 경로에 fixed.ps1이라는 명칭의 후속 로더 스크립트를 사전에 드롭하여 배치하는 기민함을 보여준다.

## 2. Persistence & Privilege Escalation

초기 거점을 확보한 Cloud Atlas는 대상 시스템에 대한 장기적인 제어권을 유지하고 단말기 재부팅 이후에도 지속성을 유지하기 위해 Windows 시스템의 자동 실행 메커니즘을 오용한다. fixed.ps1 로더 스크립트는 레지스트리의 Run 키 경로를 직접 편집하여 자신을 고정 등록함으로써, 시스템이 시동될 때마다 악성 스크립트가 백그라운드에서 자동으로 호출되는 영구 상주 구조를 확립한다.

시스템 내부 장악력을 높이기 위한 권한 상승 과정에는 Windows 내장 컴포넌트를 오용하는 기법이 동원된다. fixed.ps1에 의해 후속으로 설치되는 핵심 모듈 중 하나인 PowerShower 백도어는 호스트 내부에서 높은 관리자 권한을 획득하기 위해 윈도우 기본 유틸리티인 fodhelper.exe의 동작 구조를 악용한다. 이를 통해 {% include wiki_link.html text="사용자 계정 컨트롤(UAC)" url="/review/Details/UAC" %} 인가 알림을 우회하여 방어자의 별도 승인 없이도 커널 및 고권한 시스템 자원에 접근할 수 있는 특권 권한을 안정적으로 탈취한다.

## 3. Defense Evasion

본 캠페인에서 식별된 가장 강력한 방어 회피 전술은 완벽한 안티 포렌식 흔적 지우기와 정상 소프트웨어 구조를 교란하는 마스커레이딩(Masquerading) 기술의 융합이다. PowerShell 로더는 실행 직후 임시 경로에 미끼 압축 파일을 설치하고 내부의 정상 PDF 문서를 화면에 강제로 팝업시킨다. 이 디코이 문서는 조직의 실제 정상 워크플로우와 관련된 업무 파일인 것처럼 위장하여 방어자와 사용자의 의심을 분산시키는 차단 장치로 기능하며, 사용자가 문서를 확인하는 30~120초의 백그라운드 시간을 확보해 준다.

악성 거점 확보와 디코이 가동 작업이 완료되면, 사후 포렌식 추적을 차단하기 위해 흔적을 소멸한다. 스크립트는 페이로드 전개 과정에서 매개체로 악용했던 임시 압축 해제 도구인 winrar.exe 프로세스를 taskkill.exe 명령어로 강제 정지시킨 후, 가동에 활용된 원본 압축본, 디코이의 압축 잔재, 최초 진입점이 되었던 바로가기 파일 링크들을 디스크 공간에서 전량 강제 삭제한다.

또한 최종 백도어 모듈인 PowerCloud 및 Browser checker 스크립트는 보안 솔루션의 텍스트 기반 스크립트 탐지 필터를 우회하기 위해 PS2EXE 유틸리티를 사용하여 컴파일된 독자적인 독립 실행 파일(.exe) 형태로 외형을 정교하게 마스커레이딩하였다. 이 중 Browser checker 모듈은 Chrome, Edge, Firefox 등 브라우저 프로세스의 가동 상태를 실시간 탐색하여 사용자가 실제로 컴퓨터 앞에서 작업 중인지를 정밀 감지한다. 공격자는 이 정찰 정보를 바탕으로 사용자가 자리를 비웠으나 브라우저 세션은 유지되어 있는 최적의 타이밍을 선별하여 악성 행위를 전개함으로써 자신들의 노출 가능성을 극도로 낮추는 치밀함을 보여주었다.

더불어 공격자들은 표준 OpenSSH 바이너리의 파일 구조를 직접 개작하는 고도의 우회 전술을 구사했다. 이들이 컴파일하여 배포한 휴대용 OpenSSH 실행 파일은 가져오기 테이블의 의존성 정보를 조작하여, 원래 로드해야 하는 정상 암호화 라이브러리인 libcrypto.dll 대신 동일한 폴더에 사전에 배치해 둔 악성 syruntime.dll을 임포트하도록 강제 설정되어 있었다. 이는 엔드포인트 솔루션이 정상적인 원격 제어 프로세스의 구동 흐름으로 인지하도록 유도하여 차단망을 우회하려는 목적을 지닌다.

## 4. Credential Access & Discovery

Cloud Atlas의 최종 목표인 사이버 에스피오나지를 달성하기 위한 정보 탈취 및 정찰 기능은 각 백도어 패밀리별로 정교하게 역할이 분담되어 실행된다. 먼저 fixed.ps1에 의해 다운로드되는 VBCloud 백도어 드로퍼는 내부에 하드코딩된 키를 사용하는 RC4 암호화 알고리즘 기반의 vbs 스크립트를 가동하여 복호화된 본체를 메모리에 은밀히 로드한다. 이 VBCloud 모듈은 주로 문서 파일 유출에 집중하여 DOC, PDF, XLS 등 특정 확장자를 가진 기밀 문서 자산을 표적으로 삼아 네트워크 외부로 유출하는 임무를 수행한다.

반면 두 번째 백도어인 PowerShower 모듈은 주로 피해자 인프라 내부의 자격 증명 탈취와 상세한 디스커버리 작업에 집중한다. PowerShower는 실행 중인 전체 프로세스 아키텍처, 시스템 관리자 그룹 구성원 명세, 그리고 Active Directory 도메인 컨트롤러와의 연결 상태를 전방위적으로 스캔하여 정찰 데이터를 축적한다. 이와 동시에 도메인 환경의 자격 증명을 탈취하기 위해 Active Directory 계정의 암호 해시를 사냥하는 Kerberoasting 공격을 수행한다.

더욱 강력한 계정 정보 탈취를 위해 이들은 볼륨 섀도 복사본(Volume Shadow Copy) 메커니즘을 악용하는 별도의 자격 증명 그래버 스크립트를 추가로 다운로드하여 실행한다. 이 스크립트는 운영체제가 구동 중인 상태에서는 직접 접근이 불가능한 핵심 보안 파일 시스템에 접근하기 위해 C:\ 드라이브의 볼륨 섀도 복사본을 강제로 생성한다.

그 후, 복사된 새 섀도 볼륨 영역으로부터 시스템의 모든 로컬 계정 및 도메인 자격 증명 해시가 암호화되어 보관된 SAM 및 SECURITY 하부 시스템 구성 파일을 무단 복사한다. 이렇게 탈취된 보안 핵심 파일들은 EDR 솔루션의 유출 탐지 필터를 우회하기 위해 일반적인 PDF 파일 확장자를 가진 문서인 것처럼 교묘히 위장되어 안전하게 외부로 반출된다.

최종적으로 가동되는 신종 PowerCloud 백도어는 확보된 고권한 관리자 세션을 기반으로 사용자의 민감 데이터를 광범위하게 수집한 뒤, 수집된 로우 레벨 원시 텍스트 정보를 보안 분석가가 패킷 분석으로 식별하기 어렵게 Base64 포맷으로 인코딩 변환한다. 이후 이를 합법적인 클라우드 서비스인 구글 스프레드시트의 API를 호출하여 행 단위로 기록하는 방식으로 데이터를 최종 유출하는 지능적인 데이터 반출 채널을 운용하였다.

## 5. Lateral Movement & Command and Control

### 다중 원격 세션 확보를 통한 측면 이동 기법 (Lateral Movement)

공격자들은 내부망을 자유롭게 가로지르며 측면 이동을 수행하기 위해 Windows 시스템의 원격 데스크톱 강제 제한 규칙을 무력화하는 rdp_new.ps1 스크립트를 전개하였다. 이 스크립트는 윈도우 원격 데스크톱 서비스의 내부 라이브러리이자 다중 연결 제한 규칙을 강제하는 핵심 바이너리인 termsrv.dll 파일을 직접 타깃으로 삼는다.

스크립트는 먼저 호스트의 방화벽 규칙을 수정하여 RDP 포트를 활성화하고 관련 보안 제어 설정을 낮춘 뒤, termsrv.dll 파일의 파일 소유권을 강제로 빼앗아 자신에게 모든 권한을 부여한다. 이후 파일 내부의 특정 조건문 바이트 시퀀스를 탐색하여 원격 세션 무제한 허용을 의미하는 기계어 코드로 직접 패치한 후 원격 데스크톱 서비스를 재시작한다.

이 고위험 패치 작업을 통해 Windows 10 환경에서 다중 원격 데스크톱 세션 동시 접속 제한이 완벽히 제거된다. 결과적으로 공격자는 현재 PC를 사용 중인 실제 정당한 사용자의 화면 연결을 끊거나 로그아웃시키는 충돌 현상을 일으키지 않고, 사용자의 눈을 피해 백그라운드에서 독립적인 RDP 세션을 열고 진입하여 자유롭게 내부 원격 제어를 수행할 수 있게 되며, 사내 보안 모니터링 환경에서 발각될 확률을 극도로 낮추는 은밀한 측면 이동 통로를 확보하게 된다.

### 다중화된 백업 제어 채널 아키텍처 (Command and Control)

Cloud Atlas가 보여주는 가장 위협적인 인프라적 특성은 메인 백도어가 유출되어 전사적인 차단 조치가 이루어지더라도 지속적인 통제 권한을 유지할 수 있도록 오픈소스 및 써드파티 공개 유틸리티를 복합적으로 결합한 다중화된 하이브리드 C2 터널링 아키텍처를 구축했다는 점이다.

첫 번째 축은 광범위하게 배포된 역방향 SSH 터널링(Reverse SSH Tunneling) 체계이다. 일반적인 원격 제어 백도어들이 외부에서 내부로 접속하는 인바운드 트래픽 차단 방화벽 정책에 걸리는 것과 달리, 이들은 감염된 호스트가 공격자의 외부 제어 서버를 향해 SSH 아웃바운드 연결을 먼저 수립하도록 유도하는 역방향 터널을 개통한다.

공격자들은 시스템 내부에서 PsExec 또는 PAExec과 같은 합법적인 프로세스 실행 도구를 오용하여 터널 제어용 vbs 스크립트 삼합체를 구동하는데, 키를 생성하는 Gen.vbs, 터널을 가동하는 Run.vbs, 프로세스를 강제 정지시키는 Kill.vbs를 유기적으로 순회시킨다. 또한 윈도우 스케줄러에 실행 명령을 주기적으로 등록하여 상주성을 확보하는 한편, 보안 관리자가 개인 키 파일을 발견하여 세션을 임의로 수정하거나 차단하지 못하도록 해당 키가 포함된 폴더의 보안 접근 권한 성격 자체를 무단으로 재설정하여 잠금 처리하는 치밀함을 보였다.

두 번째 축은 Golang 언어로 작성된 리버스 프록시 도구인 RevSocks의 교차 운용이다. 공격자들은 SSH 터널링의 대안이자 네트워크 세그먼트 확장 관문으로 RevSocks를 기동하였다. 이 도구는 감염된 일선 워크스테이션을 내부망 진입을 위한 최종 게이트웨이로 탈바꿈시켜, 공격자가 외부에서 해당 PC를 징검다리 삼아 다이렉트로 로컬 네트워크의 다른 세부 구역 및 보안 세그먼트 전체에 접근할 수 있도록 경로를 프록시 포워딩한다. 이 인프라의 C2 도메인 정보는 EDR의 문자열 추출을 방해하기 위해 바이너리 내부에 하드코딩되거나 실행 시 명령행 인자를 통해 동적으로 전달되는 구조를 취했다.

세 번째 축은 추적을 원천 차단하기 위한 Tor 터널링 네트워크의 융합이다. 이들은 감염된 기기의 시스템 디렉터리 내부로 히든 서비스(HiddenService) 구동에 필요한 최소한의 핵심 Tor 실행 파일과 환경 설정 세트를 조용히 복사한 후, 백신 솔루션의 프로세스 모니터링을 피하기 위해 Tor 브라우저 관련 파일명을 정상 윈도우 파일처럼 교묘히 변조하였다.

이후 해당 호스트에서 독자적인 암호화 .onion 도메인을 동적으로 생성 및 활성화함으로써, 공격자는 전 세계 Tor 익명 라우팅 노드들을 거쳐 방화벽을 우회한 상태로 감염된 PC의 RDP 서비스 포트에 직접 다이렉트로 인바운드 접근할 수 있는 완벽한 백업 제어 채널을 완성하였다. 이러한 3중 터널링 구조는 네트워크 보안 관제 센터에서 특정 C2 지표를 식별하여 차단하더라도 다른 채널로 즉시 자가 회유하는 치명적인 탄력성을 제공한다.


# [MITRE ATT&CK Mapping]

## Initial Access

* **Phishing: Spearphishing Attachment** - [T1566.001](https://attack.mitre.org/techniques/T1566/001/)
    
    악성 바로가기(LNK) 파일이 내장된 ZIP 압축 아카이브를 스피어 피싱 이메일에 첨부하여 타깃 조직 내부로 유포하는 최초 침투 전술을 전개함.

## Execution

* **User Execution: Malicious File** - [T1204.002](https://attack.mitre.org/techniques/T1204/002/)
    
    피해자가 수신된 이메일 첨부파일의 압축을 해제하고 교묘하게 업무 문서로 위장된 바로가기(LNK) 자산을 직접 가동하도록 사회 공학적 유도 기법을 구사함.

* **Command and Scripting Interpreter: PowerShell** - [T1059.001](https://attack.mitre.org/techniques/T1059/001/)
    
    바로가기 실행 즉시 커맨드 라인을 통해 외부 원격 서버에 호스팅된 악성 PowerShell 스크립트를 호출하고, 임시 폴더에 fixed.ps1 후속 로더를 생성하여 안정적인 대리 실행 파이프라인을 형성함.


* **Exploitation for Client Execution** - [T1203](https://attack.mitre.org/techniques/T1203/)
    
    마이크로소프트 오피스 수식 편집기의 오래된 문서 구조적 취약점인 CVE-2018-0802를 교차 악용하는 악성 문서를 전달하여 사용자의 별도 개입 없이 원격 코드가 다운로드되고 실행되도록 유도함.


## Persistence & Privilege Escalation

* **Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder** - [T1547.001](https://attack.mitre.org/techniques/T1547/001/)
    
    단말기 재부팅 이후에도 지속적인 인프라 통제권을 확보하기 위해 fixed.ps1 로더 스크립트를 윈도우 레지스트리의 Run 키 경로에 자동 실행 항목으로 영구 상주 등록함.


* **Abuse Elevation Control Mechanism: Bypass User Account Control** - [T1548.002](https://attack.mitre.org/techniques/T1548/002/)
    
    권한 상승 및 정찰을 전담하는 PowerShower 백도어 구동 시 시스템 내장 유틸리티인 fodhelper.exe의 권한 관리 허점을 오용하여 별도의 보안 인가 알림 없이 관리자 특권 권한을 탈취함.


## Defense Evasion

* **Indicator Removal: File Deletion** - [T1070.004](https://attack.mitre.org/techniques/T1070/004/)
    
    거점 확보 완료 후 사후 포렌식 추적을 차단하기 위해 winrar.exe 프로세스를 강제 종료하고, 임시 폴더의 원본 압축본, 디코이 잔재, 최초 진입점이 되었던 바로가기 파일 링크들을 디스크 공간에서 전량 강제 삭제함.

* **Masquerading: Match Legitimate Name or Location** - [T1036.005](https://attack.mitre.org/techniques/T1036/005/)
    
    보안 솔루션의 텍스트 기반 탐지 필터를 회피하기 위해 PowerCloud 및 Browser checker 백도어를 PS2EXE 도구로 컴파일하여 정상 실행 파일(.exe) 외형으로 마스커레이딩함. 또한 Tor 익명화 프로세스 파일명을 정상 시스템 구성 요소로 변조하고, 정상 PDF 디코이를 화면에 강제 팝업시켜 의심을 분산시킴.


* **Hijack Execution Flow: DLL Side-Loading** - [T1574.002](https://attack.mitre.org/techniques/T1574/002/)
    
    정상 OpenSSH 실행 파일의 가져오기 테이블 의존성 정보를 변조하여 원래 로드해야 하는 정상 암호화 라이브러리 대신 동일 폴더에 악의적으로 배치한 syruntime.dll을 강제 임포트하도록 유도함.


## Credential Access & Discovery

* **OS Credential Dumping: Security Account Manager** - [T1003.002](https://attack.mitre.org/techniques/T1003/002/)
    
    운영체제 구동 상태에서 접근이 불가능한 핵심 계정 데이터베이스를 탈취하기 위해 볼륨 섀도 복사본을 강제 생성한 후, 복사된 영역에서 SAM 및 SECURITY 시스템 파일을 무단 복사하여 PDF 파일 확장자로 위장 유출함.


* **Steal or Forge Kerberos Tickets: Kerberoasting** - [T1558.003](https://attack.mitre.org/techniques/T1558/003/)
    
    내부망 횡적 이동의 교두보를 다지기 위해 Active Directory 도메인 환경 내부를 정밀 공략하여 서비스 계정의 암호 해시를 집중 수집하는 Kerberoasting 공격을 수행함.


* **System Information Discovery** - [T1082](https://attack.mitre.org/techniques/T1082/) / **Process Discovery** - [T1057](https://attack.mitre.org/techniques/T1057/)
    
    PowerShower 백도어 및 브라우저 감시 모듈을 기동하여 실행 중인 전체 프로세스 아키텍처, 관리자 그룹 명세, 도메인 컨트롤러 연결 상태, 그리고 사용자의 실제 PC 작업 타이밍과 행동 습관을 정밀 정찰함.


## Lateral Movement

* **Remote Services: Remote Desktop Protocol** - [T1021.001](https://attack.mitre.org/techniques/T1021/001/)
    
    내부망을 가로지르며 침투할 때 정당한 실제 사용자의 화면 세션이 끊겨 적발되는 현상을 차단하고자 원격 데스크톱 서비스 라이브러리인 termsrv.dll 파일의 소유권을 가로채고 특정 조건문 바이트 시퀀스를 직접 패치하여 Windows 10의 다중 원격 데스크톱 동시 접속 제한을 무력화함.



## Command and Control

* **Protocol Tunneling** - [T1572](https://attack.mitre.org/techniques/T1572/)
    
    네트워크 경계선의 인바운드 차단 방화벽 정책을 무력화하기 위해 호스트 내부에서 아웃바운드 세션을 먼저 시작하는 역방향 SSH 터널링을 구축함. 이에 더해 고랭 기반의 RevSocks 리버스 프록시 및 Tor 익명 은닉 네트워크 아키텍처(.onion 히든 서비스)를 복합 융합하여 치명적인 탄력성을 지닌 다중화된 백업 제어 채널을 구성함.


* **Exfiltration Over Web Service: Exfiltration Over Cloud Service** - [T1567.002](https://attack.mitre.org/techniques/T1567/002/)
    
    신종 PowerCloud 백도어를 가동하여 덤핑된 중요 사용자 자산 데이터를 Base64 포맷으로 인코딩한 후, 합법적인 구글 스프레드시트 API 채널을 오용하여 탐지망을 우회한 상태로 데이터를 최종 외부에 반출함.
