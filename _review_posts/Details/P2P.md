# [P2P(Peer-to-Peer)]

## P2P의 기본 개념과 분산형 아키텍처 특성

P2P는 중앙 집중식 서버의 중재 없이 네트워크에 참여하는 개별 노드(Peer)들이 동등한 권한과 책임을 가지고 서로 직접 데이터를 주고받는 분산형 네트워크 아키텍처이다. 기존의 전통적인 클라이언트-서버 모델에서는 서비스를 요청하는 단말기와 이를 처리하는 고성능 중앙 서버가 명확히 분리되어 있어, 모든 트래픽이 서버로 집중되는 구조적 병목 현상과 데이터 종속성이 존재했다. 반면 P2P 모델에 참여하는 각 노드는 자원을 소비하는 클라이언트의 역할과 자원을 공급하는 서버의 역할을 동시에 수행하는 독립적인 컴포넌트로 동작한다. 이 구조적 특성 덕분에 데이터와 네트워크 부하가 전체 망에 고르게 분산되며, 대규모 서버 인프라를 구축하지 않고도 새로운 노드가 추가될수록 전체 네트워크의 대역폭과 저장 용량이 기하급수적으로 확장되는 고유의 확장성을 지닌다.

## 사이버 위협 환경에서의 P2P 봇넷 진화 메커니즘

공격 그룹들은 이러한 P2P의 강력한 자가 조직화 및 분산 특성을 악성코드 명령 제어 체계에 이식하여 P2P Botnet 아키텍처를 고도화해 왔다. 고도화된 악성코드는 중앙에 고정된 단일 C2 서버 주소에 의존하지 않는다. 대신 감염된 시스템들이 서로의 IP 주소와 활성화된 통신 포트 목록을 피어 리스트 형태로 공유하고 동적으로 업데이트하며 유지 관리한다. 공격자가 네트워크 내의 임의의 노드 하나에 원격 제어 명령이나 추가 악성 모듈을 주입하면, 해당 명령은 분산 해시 테이블(DHT) 알고리즘이나 인접 피어들에게 데이터를 전파하는 플러딩 기법을 통해 봇넷 전체로 유기적으로 확산된다. 또한 가공된 트래픽을 중계하는 다단계 프록시 터널링 통신을 구현하여, 공격자의 실제 마스터 C2 인프라가 은닉된 최종 종착지를 추적하는 것을 철저히 차단한다.

## 회복 탄력성과 방어 및 추적 관점의 인텔리전스 시사점

보안 및 사고 대응 관점에서 P2P Botnet이 지닌 가장 치명적인 위협은 단일 장애점(Single Point of Failure)이 존재하지 않는 극단적인 회복 탄력성이다. 기존의 중앙 집중식 C2 체계에서는 핵심 도메인을 압수하거나 도메인 이름 시스템을 변조하여 싱크홀링 서버로 트래픽을 유도하면 전체 봇넷 제어권을 한 번에 무력화할 수 있었다. 하지만 P2P 봇넷은 감염망 내부의 특정 노드나 통신 경로가 차단되더라도, 살아남은 주변 피어들을 통해 실시간으로 연결을 재구축하는 자가 치유 성능을 보여준다. 인프라 전반에 걸친 동시다발적인 정화 작업이 수행되지 않는 한 완전한 박멸이 불가능에 가깝기 때문에, 방어자는 단일 지표 차단 정책을 지양해야 한다. 대신 노드 간에 발생하는 비정상적인 상호 연결 스트림을 탐지하는 행위 기반 네트워크 트래픽 감시를 가동해야 하며, 감염 징후가 포착된 단말을 즉각적으로 격리하는 제로 트러스트 분할 통제 전략이 필수적으로 요구된다.
