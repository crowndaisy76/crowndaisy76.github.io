# [NETLOGON]

## NETLOGON의 기본 개념과 도메인 인증 아키텍처

NETLOGON은 Windows Server 아키텍처 환경에서 도메인 제어 및 자격 증명 인증을 총괄하는 핵심 서비스이자 프로토콜이다. Active Directory 도메인에 가입된 멤버 워크스테이션이나 일선 서버가 도메인 컨트롤러(DC)와 안전하게 통신할 수 있도록 보안 채널(Secure Channel)을 수립하고 유지 관리하는 결정적인 역할을 수행한다. 사용자가 도메인 환경의 특정 PC에 로그인을 시도할 때, 로컬 시스템은 해당 인증 요청을 직접 처리하지 않고 NETLOGON 서비스를 통해 도메인 컨트롤러로 안전하게 릴레이하여 유효성을 검증받는다. 또한 전사 네트워크 환경에서 특정 단말기가 자신을 신뢰하고 인증해 줄 수 있는 올바른 도메인 컨트롤러를 탐색하는 DC Locator 메커니즘의 기반이 되며, 도메인 환경의 신뢰성 높은 중앙 집중식 인프라를 지탱하는 인증 파이프라인의 핵심 축으로 동작한다.

## 통신 메커니즘과 세션 수립 프로세스

NETLOGON 서비스는 내부적으로 MS-NRPC(Netlogon Remote Protocol)라는 마이크로소프트 전용 RPC 규격을 사용하여 호스트 간 통신을 수행한다. 최초 단말기가 부팅되거나 네트워크에 연결되면, MSRPC 엔드포인트 매퍼(TCP 135번 포트)를 통해 통신 채널을 협상한 뒤 지정된 Named Pipes 스트림이나 SMB 프로토콜(TCP 445번 포트)을 거쳐 도메인 컨트롤러와 난수 기반의 챌린지-응답(Challenge-Response) 인증 과정을 교환한다. 이 인증 단계를 통과하면 양측은 컴퓨터 계정의 비밀번호를 기반으로 공유 비밀키를 생성하고, 이후 오가는 모든 통신 패킷의 무결성과 기밀성을 보장하는 세션 키를 유도하여 최종 보안 채널을 개통한다. 이 동적 보안 채널이 성공적으로 확립되어야만 단말기 패스워드 변경 내역 동기화, 그룹 정책 객체(GPO) 업데이트 수신, 그리고 신뢰 관계에 있는 상이한 도메인 포레스트 간의 교차 인증 처리가 호스트 레벨에서 유기적으로 전개될 수 있다.

## 침해 사고 관점에서의 위험성과 취약점 분석

APT 침해 사고 및 내부망 횡적 이동(Lateral Movement) 관점에서 NETLOGON 시스템은 공격자들에게 가치가 매우 높은 전술적 표적이다. 도메인 환경 내의 모든 컴퓨터가 읽기 권한을 가지는 NETLOGON 공유 폴더(일반적으로 도메인 컨트롤러의 SYSVOL 내부 스크립트 경로와 동기화됨)는 공격자가 사내 전체 단말기에 데이터 파괴 배치 파일이나 악성 바이너리를 대량으로 유포하기 위한 중앙 집중식 거점으로 악용되기 쉽다.
