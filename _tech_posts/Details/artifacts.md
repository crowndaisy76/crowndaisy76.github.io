## 프로세스 및 메모리 진단 아티팩트

* **/proc/meminfo:** 내부의 메모리 할당량 데이터를 조회하여 시스템의 총 물리 메모리 크기를 식별한다.
* **/proc/[PID]:** ps 명령어 테이블에 존재하지 않으나 해당 경로에 물리적인 숫자로 잔존하는 디렉토리를 대조하여 은닉 프로세스 유무를 검증한다.

## 사용자 계정 및 권한 감사 아티팩트

* **/etc/passwd:** 계정 정보 파일 내 세 번째 필드인 UID 값을 전수 조사하여 root(0) 외에 추가적인 최고 권한 계정이 상주하는지 확인한다.
* **/etc/shadow:** 사용자 패스워드 해시 필드를 조회하여 비밀번호 문자열이 공백으로 설정된 취약한 계정을 적발한다.
* **/etc/doas.conf:** doas 권한 설정 파일의 소유권과 물리 비트를 대조하여 일반 사용자의 무단 수정 권한이 허용되어 있는지 확인한다.
* **/etc/sudoers:** sudo 권한 설정 아티팩트의 파일 권한 플래그를 점검하여 비인가 변조 가능성을 검증한다.
* **/etc/login.defs:** 시스템 계정 인증 정책 아티팩트를 조회하여 패스워드 최소/최대 유지 기간 설정값을 검증한다.
* **/etc/securetty:** 루트 권한 로그인이 허용된 보안 터미널 타겟 목록을 전수 조사한다.
* **/etc/group:** 시스템 그룹 정의 파일 내 비인가 계정이 특정 관리자 그룹에 추가되어 있는지 전수 조사한다.
* **/etc/gshadow:** 그룹 암호화 파일의 보안 필드 상태 데이터를 확인한다.
* **/etc/security/limits.conf:** 시스템 자원 사용 한도 설정 아티팩트를 검증한다.
* **/etc/security/opasswd:** 과거 패스워드 기록 저장 아티팩트를 검사하여 비밀번호 재사용 주기 설정을 확인한다.

## 운영체제 및 배포판 식별 데이터 아티팩트

* **/etc/os-release:** 운영체제 배포판의 명칭 및 버전 식별자 메타데이터를 추출하여 진단 세션 변수를 확정한다.
* **/etc/redhat-release:** Red Hat 계열 배포판의 주 버전 및 상세 빌드 문자열 데이터를 수집한다.
* **/etc/debian_version:** Debian 계열 배포판의 릴리즈 버전 기록 필드를 조회한다.
* **/etc/issue:** 원격 접속 전 터미널에 표기되는 시스템 정보 배너 아티팩트를 확인한다.
* **/etc/issue.net:** 네트워크 RDP/SSH 접속 전 노출되는 외부 배너 아티팩트 설정을 점검한다.
* **/etc/motd:** 로그인 성공 시 사용자에게 표기되는 배너 정보 메타데이터를 파싱한다.

## 시스템 스케줄러 및 지속성 감사 아티팩트

* **/etc/cron.d:** 시스템 전역 스케줄러 디렉토리 내에 인가되지 않은 백도어 스크립트 파일이 은닉되어 있는지 전수 검색한다.
* **/etc/cron.daily:** 매일 자동 실행되는 스케줄러 파일 목록의 무결성과 비인가 바이너리 유입을 점검한다.
* **/etc/cron.hourly:** 시간 단위로 호출되는 스케줄러 영역의 스크립트 실행 인자를 분석한다.
* **/etc/cron.weekly:** 주간 단위 자동 실행 경로 내에 상주하는 설정 파일 데이터를 전수 조사한다.
* **/etc/cron.monthly:** 월간 단위 스케줄러 관리 파일 내에 등록된 실행 경로의 안전성을 검증한다.
* **/var/spool/cron/crontab:** 개별 사용자 계정별로 생성된 cron 큐 아티팩트를 순회하며 악성 명령어 포함 여부를 검사한다.
* **/etc/anacrontab:** 주기적 스케줄러 비정기 실행 제어 아티팩트의 구성을 검증한다.
* **/etc/at.allow:** 특권 작업 예약(at) 명령어가 허용된 계정 목록 아티팩트를 검사한다.
* **/etc/at.deny:** 작업 예약 접근이 거부된 계정 데이터 필드를 식별한다.
* **/etc/cron.allow:** cron 스케줄러 사용이 허가된 명단 화이트리스트 아티팩트를 파싱한다.
* **/etc/cron.deny:** cron 스케줄러 사용이 제한된 계정 목록 블랙리스트 아티팩트를 파싱한다.

## 부팅 및 서비스 관리 아티팩트

* **/etc/rc.local:** 부팅 시 자동 실행되는 스크립트 파일 내부에 백도어 구동 명령어가 오픈되어 있는지 확인한다.
* **/etc/systemd/system/:** systemd 기반 자동 시작 서비스 유닛 파일 내부의 ExecStart 필드를 파싱하여 임시 경로에서 실행되는 파일 플래그를 적발한다.
* **/etc/init.d/:** SysVinit 방식 부팅 스크립트 디렉토리 내부에 등록된 서비스 실행 인자의 무결성을 점검한다.
* **/etc/inittab:** 시스템 초기 런레벨 및 부팅 제어 환경 아티팩트를 검사한다.

## 네트워크 및 통신 감사 아티팩트

* **/etc/resolv.conf:** 네임서버 등록 아티팩트를 조회하여 악성 DNS 변조 및 활성화된 네임서버 개수를 식별한다.
* **/etc/hosts:** 로컬 도메인 맵핑 아티팩트 내의 IP 및 호스트네임 변조 여부를 확인한다.
* **/etc/host.conf:** 도메인 이름 확인 순서 정의 파일의 메타데이터를 파싱한다.
* **/etc/networks:** 시스템 네트워크 이름 구성 아티팩트의 상태 정보를 수집한다.
* **/etc/protocols:** 파일 시스템 내에 상주하는 표준 네트워크 프로토콜 정의 아티팩트의 무결성을 확인한다.
* **/etc/services:** 포트 번호와 서비스 명칭 매핑 파일의 변조 여부를 검증한다.
* **/proc/net/tcp:** 가상 네트워크 소켓 상태 아티팩트를 참조하여 LISTEN 상태로 오픈된 비인가 로컬 포트를 전수 추출한다.
* **/proc/net/udp:** 실시간 UDP 소켓 통신 바인딩 상태 데이터를 파싱한다.
* **/etc/ssh/sshd_config:** SSH 데몬 설정 파일 내부를 파싱하여 루트 로그인 허용 여부 및 취약한 암호화 알고리즘 활성화 필드를 검사한다.
* **/etc/xinetd.conf:** 확장 슈퍼 데몬 설정 아티팩트를 파싱하여 백도어 포트가 서비스 형태로 대기 중인지 확인한다.
* **/etc/xinetd.d/:** 개별 네트워크 서비스 활성화 필드의 무결성을 조사한다.

## 로그 및 흔적 추적 아티팩트

* **/var/log 내 활성 로그 파일:** lsof 명령어가 반환하는 물리 프로세스 참조 목록 중 크기가 0 바이트인 활성 로그 스트림을 추적하여 침해 흔적 삭제 행위를 탐지한다.
* **/etc/syslog.conf:** 시스템 로그 데몬의 저장 규칙 아티팩트를 파싱하여 감사 로그가 비인가 경로로 무단 유출되거나 누락되는지 검증한다.
* **/etc/rsyslog.conf:** 확장 rsyslog 데몬의 원격 로그 전송 필드 및 필터링 조건을 파싱한다.
* **/etc/syslog-ng/syslog-ng.conf:** 차세대 로그 매니저인 syslog-ng 아티팩트의 소스 및 목적지 필드를 확인한다.
* **/etc/logrotate.conf:** 로그 순회 및 보존 주기 설정 파일의 파라미터를 검증한다.
* **/etc/logrotate.d/:** 개별 서비스별로 정의된 로그 순회 규칙 아티팩트 디렉토리를 전수 점검한다.
* **/var/run/utmp:** 현재 시스템에 실시간 로그인 중인 사용자 세션 정보 바이너리 아티팩트를 파싱한다.
* **/var/log/wtmp:** 과거부터 현재까지 성공한 모든 로그인/로그아웃 이력을 축적하는 핵심 인증 로그 아티팩트를 검증한다.
* **/var/log/btmp:** 시스템 접속에 실패한 악성 인증 시도 레코드를 전수 파싱한다.
* **/var/log/lastlog:** 각 사용자 계정별 최종 로그인 시각 및 IP 주소 필드 메타데이터를 파싱한다.
* **/etc/systemd/journald.conf:** systemd 저널 로그의 영구 저장 모드 및 용량 제한 변수를 확인한다.

## 패키지 및 소프트웨어 관리 아티팩트

* **/etc/yum.conf:** 패키지 관리자 전역 설정 아티팩트의 신뢰성을 검사한다.
* **/etc/yum.repos.d/:** 외부 패키지 저장소 주소를 전수 검사하여 악성 바이너리가 다운로드되는 비인가 경로 유입 여부를 판단한다.
* **/etc/apt/sources.list:** Debian/Ubuntu 계열의 공식 소스 리스트 아티팩트 필드를 조회하여 비인가 외부 패키지 서버 주소를 식별한다.
* **/etc/apt/sources.list.d/:** 추가 등록된 외부 서드파티 저장소 아티팩트 파일의 무결성을 점검한다.
* **/var/lib/dpkg/status:** 데비안 계열 시스템에 설치된 전체 패키지의 무결성과 상태 기록 아티팩트를 대조한다.
* **/var/lib/rpm/__db001:** RPM 기반 시스템의 설치 바이너리 인덱스 데이터베이스의 존재 여부를 검증한다.

## 시스템 하드닝 및 파일 시스템 아티팩트

* **/etc/sysctl.conf:** 커널 파라미터 구성 아티팩트를 파싱하여 메모리 보호 기법 및 네트워크 하드닝 설정 값을 대조한다.
* **/etc/fstab:** 파일 시스템 마운트 설정 아티팩트를 참조하여 마운트 옵션의 무결성을 확인한다.
* **/etc/mtab:** 현재 파일 시스템에 마운트되어 구동 중인 라이브 파티션 상태 아티팩트를 조회한다.
* **/etc/selinux/config:** SELinux 강제 제어 아티팩트 내의 동작 모드 필드를 확인하여 강제적 접근 통제 메커니즘의 우회 유무를 판단한다.
* **/etc/apparmor.d/:** AppArmor 보안 프로파일 디렉토리의 유닛 파일 구성을 조사한다.
* **/proc/sys/fs/file-max:** 커널이 할당 가능한 최대 파일 지시자 개수 설정 아티팩트를 확인한다.
* **/proc/sys/kernel/pid_max:** 시스템의 최대 프로세스 식별자 생성 한도값을 점검한다.
* **/proc/sys/kernel/randomize_va_space:** ASLR 기법 활성화 필드값을 직접 조회하여 메모리 오염 공격 방어 상태를 검증한다.
* **/proc/sys/net/ipv4/ip_forward:** 커널 내부의 패킷 포워딩 플래그를 검사하여 해당 서버가 중간자 공격 경로나 비인가 라우터로 악용되는지 판단한다.
* **/proc/sys/net/ipv4/conf/all/accept_redirects:** ICMP 리다이렉트 패킷 수용 필드를 점검하여 라우팅 테이블 변조 취약성을 확인한다.

## 보안 감사 및 무결성 아티팩트

* **/etc/audit/auditd.conf:** 커널 수준 보안 감사 추적 데몬의 설정 파일 무결성을 점검한다.
* **/etc/audit/rules.d/:** 실시간 파일 시스템 및 시스템 콜 모니터링 감사 규칙 아티팩트를 파싱한다.
* **/etc/ldap.conf:** 시스템이 참조하는 LDAP 클라이언트 설정 파일의 위치와 매개변수를 전수 조사한다.
* **/etc/openldap/ldap.conf:** OpenLDAP 환경의 인증 경로 및 설정 아티팩트 존재 여부를 확인한다.
* **/etc/pam.d/:** 플러그인 가능 인증 모듈 설정 디렉토리 내 핵심 인증 제어 플래그의 우회 무단 변조 여부를 점검한다.
* **/etc/pam.conf:** 구형 시스템용 전역 PAM 인증 설정 파일의 유효성을 점검한다.
* **/etc/profile:** 전역 환경 변수 설정 파일 내부에 악성 경로 하이재킹 코드가 주입되었는지 확인한다.
* **/etc/bashrc:** 인터랙티브 셸 환경 설정 아티팩트의 변조 플래그를 추적한다.
* **~/.bash_profile:** 개별 계정 홈 디렉토리 내 숨김 부팅 파일의 실행 인자를 전수 조사한다.
* **~/.bashrc:** 사용자별 셸 환경 파일에 등록된 별칭 및 악성 명령어 자동 실행 설정을 확인한다.
* **~/.ssh/authorized_keys:** 비밀번호 없이 원격 접속을 허용하는 SSH 인증 키 등록 아티팩트를 파싱하여 비인가 외부 키의 은닉 여부를 사냥한다.
* **/etc/aliases:** 메일 송수신 별칭 설정 파일 내부의 포워딩 경로 필드를 점검한다.
* **/etc/shells:** 시스템 내 가용한 정식 셸 경로 목록을 조회하여 비인가 셸 주입 여부를 식별한다.
* **/etc/printcap:** 프린터 및 스풀러 시스템 구성 정보 아티팩트를 확인한다.
