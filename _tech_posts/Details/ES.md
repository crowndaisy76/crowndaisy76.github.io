# [ES 모듈 (ES Modules)]

ES 모듈(ECMAScript Modules, 이하 ESM)은 자바스크립트 언어 자체에 공식적으로 도입된 표준 모듈 시스템이다. 2015년 ECMAScript 표준(ES6) 사양으로 정의되었으며, 브라우저와 Node.js 환경 모두에서 자바스크립트 코드를 독립된 파일 단위로 분할하고 필요에 따라 서로 불러와 재사용할 수 있도록 지원한다.

ESM이 도입되기 전 자바스크립트 생태계는 Node.js 중심의 CommonJS(CJS)와 브라우저 환경을 위한 AMD, UMD 등 다양한 비공식 모듈 시스템으로 양분되어 있었다. ESM은 이러한 파편화를 종식시키고 언어 차원에서 모듈화를 지원하기 위해 등장했다.

## 1. 정적 구조와 컴파일 타임 분석

ESM의 가장 핵심적인 특징은 정적 구조(Static Structure)를 가진다는 점이다. 기존의 CommonJS는 `require()` 함수를 코드 흐름 중간이나 조건문 내부에서 동적으로 호출할 수 있었다. 반면 ESM의 `import`와 `export` 구문은 오직 소스코드의 최상위 레벨(Top-level)에서만 선언할 수 있으며, 동적인 변수를 실행하여 모듈 경로를 지정하는 것이 불가능하다.

이러한 제약은 소프트웨어 도구 관점에서 엄청난 이점을 가져다준다. 코드를 실제로 실행(Runtime)해 보지 않고도, 구문 분석기(Parser)가 단순히 텍스트를 읽는 것만으로 전체 모듈의 의존성 관계 그래프를 완벽하게 파악할 수 있기 때문이다. 이를 **컴파일 타임 분석** 또는 정적 분석(Static Analysis)이라고 부른다.

## 2. 정적 분석이 가져다주는 이점

* **트리 쉐이킹(Tree Shaking)**: 정적 분석 덕분에 빌드 도구(Webpack, Rollup, Vite 등)는 모듈 내에서 실제로 사용되지 않는 코드를 정확하게 감지하고 최종 번들 파일에서 제거할 수 있다. 이는 결과물의 용량을 획기적으로 줄여준다.
* **성능 최적화**: 모듈 간의 연결 관계가 컴파일 단계에서 이미 결정되므로, 자바스크립트 엔진이 런타임에 모듈의 참조 관계를 찾기 위한 부하가 크게 줄어든다.
* **도구의 지원**: IDE(VS Code 등)나 구문 분석 파서들이 소스코드를 분석할 때, 모듈의 구조가 명확하게 고정되어 있으므로 자동 완성이나 타입 추론, 문법 에러 감지를 훨씬 더 정확하게 수행할 수 있다.

## 3. CommonJS(CJS)와의 핵심 차이점

두 모듈 시스템은 단순히 문법(`require` vs `import`)의 차이를 넘어 동작 메커니즘 자체가 완전히 다르다.

* **동작 시점**: CommonJS는 코드가 실행되는 런타임에 동적으로 모듈을 로드하고 평가한다. 반면 ESM은 코드가 실행되기 전, 구문 파싱 단계에서 모듈의 의존성을 먼저 수집하고 연결한다.
* **로딩 방식**: CommonJS는 동기적(Synchronous)으로 파일을 읽어 들인다. 모듈을 다 불러올 때까지 다음 코드의 실행이 차단된다. 이와 달리 ESM은 기본적으로 비동기적(Asynchronous)으로 설계되어 있어, 네트워크를 통해 모듈을 다운로드해야 하는 브라우저 환경에서도 효율적으로 작동한다.
* **참조의 성격**: CommonJS의 `require()`는 불러온 모듈의 값을 복사(Copy)하여 가져온다. 따라서 원본 모듈 내부에서 값이 바뀌어도 호출한 곳의 값은 변하지 않는다. 반면 ESM의 `import`는 실시간 읽기 전용 참조(Live Read-Only Link)를 가져오기 때문에, 원본 모듈에서 업데이트된 값이 실시간으로 반영된다.

## 4. 현대 자바스크립트에서의 ESM 확장 기능

최신 ECMAScript 사양에서는 ESM의 정적 제약을 유지하면서도 유연성을 확보하기 위해 몇 가지 중요한 기능들이 추가되었다.

* **동적 임포트 (Dynamic Import)**: 상황에 따라 모듈을 동적으로 불러와야 할 때를 위해 `import()` 함수 형태의 문법을 지원한다. 이 함수는 프로미스(Promise)를 반환하므로 비동기적으로 필요한 시점에 모듈을 로드(Lazy Loading)할 수 있게 해준다.
* **탑 레벨 어웨이트 (Top-level Await)**: 비동기 모듈 로딩 체계 덕분에, ESM 내부에서는 `async` 함수로 감싸지 않고도 최상위 레벨에서 즉시 `await` 키워드를 사용하여 비동기 처리를 수행할 수 있다.
* **임포트 어트리뷰트 (Import Attributes)**: 최신 자바스크립트 명세에서는 `import config from './config.json' with { type: 'json' };`과 같은 형태로, 자바스크립트 파일뿐만 아니라 JSON이나 CSS 같은 외부 리소스를 보안상 안전하고 명확하게 모듈로서 가져올 수 있는 메타데이터 주입 기능을 지원하고 있다.
